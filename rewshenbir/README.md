# rewshenbir.pezkiwi.app — interim landing page

What the Rewshenbir button opens until the mini-app exists. Built from the
Claude Design canvas of 2026-04-22 (its tokens, its thesis, and the logo rendered
from its `RewshenbirMark` component), in English and Turkish.

Served from VPS3 (217.77.6.126) as a static file:

    install -m 644 rewshenbir/index.html /var/www/rewshenbir.pezkiwi.app/index.html

nginx: `/etc/nginx/sites-available/rewshenbir.pezkiwi.app`, TLS by certbot.
